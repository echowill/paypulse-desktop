# 薪跳 Web

打开 [网页版](https://paypulse-echowill.decenthill26.chatgpt.site) 即可使用，面向最新桌面 Chrome。无安装包、无账号、无后端，源码为原生 HTML / CSS / JavaScript，使用 Sites 提供公开 HTTPS 网址，源码同步至此 GitHub 仓库。

## 使用

填写月薪和排班后保存；也可以先用示例体验，示例不会自动保存。工资、常规及单日排班、小目标和外观只保存在当前浏览器的本地存储，不发往服务器。换设备、换浏览器或清理网站数据不会自动迁移配置。

点击「打开桌面小窗」会使用 Chrome 的 Document Picture-in-Picture API，创建可跨应用置顶的窗口。用户可拖动标题栏移动、拖动边缘缩放，并在设置中修改字号样式、主题和显示内容。浏览器控制外边框和位置，网页无法指定桌面坐标或实现原生桌面透明效果。关闭主网页，小窗也会关闭；需要用户亲自点击按钮打开，不能自动弹出。

系统通知默认关闭，启用并保存后申请权限；通知不包含工资金额。网页保持打开时检查下班和发薪日期，关闭网页或 Chrome 后不发通知。后台冻结或系统免打扰也可能影响提醒显示。金额不依赖计时器累加，即使暂停刷新或关闭页面，重新打开后仍按实际排班区间补齐。

## 功能与口径

- 月薪、常规工作日、工作与休息时间，支持跨夜，按上班日期判断排班、按自然日拆分收入。
- 中国大陆计薪日历 / 本月排班工时 / 固定折算天数三种口径。实际排班独立展示工作日与工时，计算卡显示实时月薪、所用折算工时、完整公式和时薪；无需保存即可预览，保存后应用到主界面与小窗。
- 每日收入小目标与达成时刻估算，跳过休息，不延伸到明天；轻量庆祝尊重隐藏金额开关。
- 指定日期改班、休息（不计薪）或恢复自动安排，手动安排优先，拒绝相邻计薪时段重叠。
- 发薪日倒计时，短月取月末，不自动顺延周末；日期不代表真实到账。
- 隐藏金额、四位小数、小窗主题 / 大小 / 字体，可在浏览器本地保存。

中国大陆计薪日历内置 2025、2026 年已核对的数据，普通工作日及补班参与计薪，法定带薪节日沿用常规时段（含休息扣除）累计，调休休息日不重复计薪。界面区分实际上班工时与含带薪节日的计薪时长，完整月份累计等于月薪；带薪节日不发下班提醒。未收录年份暂停估算并提示切换口径，不使用预测日历。数据更新与来源见 [日历说明](../docs/china-calendar.md)。

改变工资或排班会回算本月，不保留历史规则；不采集考勤，不计算税费和加班倍率。估算时薪在固定口径下使用常规班计薪时长作为分母，临时班次按实际时长累计。浏览器使用设备当地时区。

## 开发与发布

无需安装依赖。Node 22+，本地预览还需要 Python 3：

```sh
npm test --prefix web
npm run build --prefix web
npm run dev --prefix web
```

本地网址为 `http://127.0.0.1:4173/`。Chrome 将本机回环地址视为可信上下文，可测试小窗；线上需要 HTTPS。GitHub Actions 执行 19 组计薪检查、生成 `web/dist` 并保存静态构建产物；正式网址通过 Sites 发布。测试涵盖午休、跨夜、重叠拒绝、月末、固定口径、日例外、目标达成时间、短月发薪、提醒计划、非法数据和夏令时。

真实桌面 Chrome 已验证小窗打开及内容实时刷新；嵌入式浏览器即使存在同名 API，也不保证有完整画中画窗口实现。用户应在独立桌面 Chrome 中打开网址。

网站向 Sites 请求静态文件，托管平台可能处理访问 IP 等普通请求信息；应用代码不会把工资和排班放进请求或网址。工资、提醒配置和排班仅保存在浏览器。源码托管在 GitHub，浏览 GitHub 时适用其隐私声明。

托管标识保存在 `.openai/hosting.json`，后续发布复用同一个 `project_id`。GitHub 中的 `public/` 是源码；Sites 使用独立源码工作区，把这些文件同步到 `dist/` 后按其发布流程打包，避免替换本仓库的 GitHub remote。凭证不进入源码或归档。
