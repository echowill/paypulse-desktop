# 薪跳 PayPulse

一个原生 macOS 菜单栏时薪计时器。Swift + SwiftUI + AppKit，无第三方依赖、无登录、无网络请求。

## 使用

双击「薪跳.app」，输入月工资并设置工作时间、休息时段和每周工作日。保存后，菜单栏会每秒刷新今天的预估收入。点击菜单栏金额打开详情，右键打开设置。可打开可拖动、跨桌面置顶的悬浮窗。

首次使用无需填写真实工资，可以先用示例数值体验。「眼睛」按钮会同时隐藏菜单栏、详情和悬浮窗里的金额。设置支持显示 4 位小数，让较低时薪的变化也容易观察。

## 1.1.0 的四页设置

- **薪资排班**：月薪、常规工作日与休息时间，以及两种计薪口径。实际排班天数和工时单独显示，固定折算天数只改变时薪。
- **浮窗外观**：小 / 中 / 大，圆润 / 系统 / 等宽数字，跟随系统 / 浅色 / 深色主题，50%–100% 的背景不透明度。可选收入与倒计时组合，文字不随背景变透明。拖动小窗、双击打开设置，右上角 × 收起；位置会保存，换屏后移回可见区域。
- **目标提醒**：启用每日收入小目标，使用咖啡 / 午饭预设或自行填写名称和金额。面板显示进度、剩余计薪时间和预计达成时刻，估算跳过休息时段。目标每天零点重置，超出今日排班可赚金额时会说明。可选轻量应用内庆祝，每天至多一次，隐藏金额时不庆祝。
- **临时排班**：选择日期，设为上班或休息，可独立设置当日时间与不计薪休息。点击「加入临时排班」加入草稿，底部保存后生效。已加入的日期可编辑或恢复常规；跨夜班归上班日，重叠班次会被拒绝。

设置页拥有独立草稿，计时刷新不会覆盖正在输入的内容。取消放弃草稿，保存一次应用各页的改动。

## 下班和发薪日提醒

系统提醒默认关闭。可选在下班时或提前 5 / 10 / 15 / 30 分钟通知，也可设置每月发薪日期、是否当天提醒以及提醒时刻。发薪日倒计时无需开启通知；选择 29–31 日遇到短月会取月末，不自动顺延周末。这是日期提醒，不代表工资实际到账。

开启系统提醒并保存后，应用才会申请 macOS 通知权限。拒绝后可在「系统设置 → 通知 → 薪跳」中开启，再保存设置。通知不显示工资或目标金额，声音可单独关闭，免打扰模式可能延后显示。

下班提醒会按当日实际班次（包括临时和跨夜排班）提前安排未来 32 天；发薪日安排接下来的 3 次提醒。应用运行时每天续排，唤醒、修改系统时间 / 时区和保存设置时会重新安排。已安排的系统提醒可在应用退出后继续显示；长期不运行超过上述范围后，需要重新打开应用续排。关闭对应开关并保存可取消待发提醒。

## 计薪规则

- 默认：秒薪 = 月薪 ÷ 本月排班计薪秒数；收入 = 当天已流逝的排班计薪秒数 × 秒薪。休息时间不参与计薪。
- 可选固定月计薪天数：秒薪 = 月薪 ÷ 固定天数 ÷ 常规班计薪秒数。这是可自行调整的估算口径，默认示例为 21.75；不代表法律或企业薪资规则。临时班次按其实际计薪时长累计，不改变常规班折算分母。
- 日收入在本机当地时间零点重置；月收入为按当前配置自当月 1 日起回算的预估收入。
- 下班时间早于上班时间表示跨夜班次。跨夜班次按上班当天判断是否排班，但收入按自然日拆分；跨月部分使用所属月份的折算时薪。
- 根据日历区间直接计算，睡眠、退出、重启后自动补齐已过去的排班时间。它统计排班时间，不监控电脑活动，也不采集考勤。
- 修改工资或排班（含临时安排）会回算本月，不保留历史薪资版本。暂不支持法定节假日 / 调休自动识别、加班倍率、税费扣除、发薪流水；特殊日期需手动设置。

## 安装与兼容性

- macOS 13 及以上，Universal 二进制，包含 Apple Silicon 和 Intel。
- 本地构建并临时签名，未使用 Apple Developer ID 签名或公证。跨电脑分发时，macOS 可能拦截；检查来源后可在系统设置「隐私与安全性」中选择「仍要打开」。无需关闭 Gatekeeper。
- 可移入「应用程序」再使用「登录 Mac 时自动启动」。是否启用以系统登录项状态为准；需要系统批准时应用会提示。
- 退出：详情底部「退出」，或应用激活时按 Command-Q。
- 数据：`~/Library/Preferences/local.paypulse.mac.plist` 中的 `salarySettings.v1`（含单日排班）与 `desktopPreferences.v1`（浮窗、目标和提醒）。兼容读取旧版设置，UserDefaults 本地存储，未加密；不上传、不跟踪。
- 删除应用前，如需取消待发系统提醒，请关闭提醒开关并保存；同时关闭登录启动。清理数据可移除上述偏好，已经显示的通知需在通知中心清除。

## 开发

需要 macOS 和支持 Swift 5.9+ 的 Xcode Command Line Tools。

```sh
swift run SalaryEngineChecks
./build.sh /absolute/output/path
```

`build.sh` 运行测试，编译两个架构，合并 Universal 可执行文件，生成应用图标并临时签名。

`open 薪跳.app --args --preview` 打开隔离的演示数据窗口，不保存为用户工资。常规启动不会使用演示数据。

`--preview --preview-view appearance` 可打开演示外观页，支持 `salary`、`goals`、`schedule`、`floating`。演示不会申请通知权限或修改登录启动项。`--preview --preview-view dashboard --export-preview /absolute/demo.png` 只导出应用自身的演示视图，不捕获用户桌面。

## 结构

- `Sources/PayPulseCore/`：纯日历区间计薪、单日覆盖、目标估算、发薪日、提醒计划与输入校验。
- `Sources/PayPulse/`：菜单栏、设置、桌面悬浮窗、偏好保存和登录项。
- `Tests/PayPulseCoreTests/`：15 组检查，覆盖午休与工作边界、周末、跨夜、月末、固定计薪、精确秒数、夏令时、旧数据迁移、单日覆盖和冲突、目标时间与隐私、发薪日和提醒计划。
